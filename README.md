# Koret Diandre – Offisiell Hjemmeside

Bygget med [Hugo](https://gohugo.io/) og hostet på [GitHub Pages](https://pages.github.com/).

## For bidragsytere

### Å legge til et nytt arrangement:
1. Kopier `content/arrangement/2025-12-15-julekonsert.md`
2. Endre dato, tittel, sted og beskrivelse
3. Push til hovedgrensen → automatisk publisering

### For redigering via nettskjema:
Gå til [https://diandre.no/admin](https://diandre.no/admin) (etter konfigurasjon)
